# API Reference

Konet exposes a WebSocket API built on Phoenix Channels.

## Endpoints

| Protocol | URL | Purpose |
|----------|-----|---------|
| WebSocket | `ws://host:4000/socket` | Channel transport |
| HTTP | `GET /api/health` | Health check |
| HTTP | `GET /api/channels` | Active channels + subscriber counts (service key) |
| HTTP | `GET /api/presence/:channel` | Presence for a channel (service key) |
| HTTP | `POST /api/broadcast` | Broadcast to a channel (service key) |
| HTTP | `GET /api/metrics` | Metrics as JSON (service key) |
| HTTP | `GET /metrics` | Prometheus text format (service key) |

## Message Format

All channel messages use JSON:

```json
{
  "event": "broadcast",
  "payload": { "text": "hi" },
  "ref": "1"
}
```

## Topics

Topics follow the pattern `room:<id>`. You can join any room dynamically; no pre-registration is required.

## Authentication

Pass a JWT as a connection parameter:

```json
{ "token": "<jwt>" }
```

Tokens must be signed with `KONET_JWT_SECRET`.
